# Userscript Images

Screenshots of the OTS browser userscript HUD overlay.

## Expected Images

### Userscript HUD
- `userscript-hud.png` - Complete HUD showing all tabs
- `logs-tab.png` - Logs tab with event filtering (optional)
- `hardware-tab.png` - Hardware status tab (optional)
- `sound-tab.png` - Sound control tab (optional)
- `settings-panel.png` - Settings/config panel (optional)

## Screenshot Guidelines

- **Game**: Overlay on actual OpenFront.io game page
- **Resolution**: 1920x1080 minimum
- **Format**: PNG
- **State**: Show HUD with actual game events (not empty)
- **Visibility**: Ensure HUD is clearly readable

## How to Capture

1. Install userscript in Tampermonkey
2. Open https://openfront.io/ and join a game
3. Open HUD (check keybind in userscript)
4. Switch between tabs to capture different views
5. Use browser screenshot tool (F12 → Ctrl+Shift+P → "Screenshot")
6. Crop and optimize
